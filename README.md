# LocalHub

FastAPI + SQLite backend and Vue test client for the Daejeon/Chungcheong LocalHub project.

## Core choices

- `data/json` is loaded into normalized location tables.
- `data/rag` is loaded into `rag_sources` and `rag_chunks`.
- RAG search uses FAISS with OpenAI embeddings when `OPENAI_API_KEY` is configured.
- The chat answer is generated by OpenAI after FAISS retrieval.
- Chat responses separate PDF/document evidence from mappable places:
  - `sources`: RAG chunks from PDF text extraction.
  - `referenced_items`: locations matched from the structured DB.

## Environment

Create `.env` at the repository root:

```bash
OPENAI_API_KEY=your_key
DATABASE_URL=sqlite:///./localhub.db
AUTO_SEED=true
FRONTEND_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
OPENAI_CHAT_MODEL=gpt-4o-mini
VECTOR_CACHE_DIR=.cache/localhub
```

## Backend run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

The app seeds SQLite automatically on startup when `AUTO_SEED=true`.
The first OpenAI-backed run builds an embedding cache under `.cache/localhub`.

## Frontend test client

```bash
cd frontend
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## API

- `GET /api/v1/locations`
- `GET /api/v1/locations/{contentid}`
- `GET /api/v1/locations/nearby`
- `GET /api/v1/posts`
- `GET /api/v1/posts/{post_id}`
- `POST /api/v1/posts`
- `PUT /api/v1/posts/{post_id}`
- `DELETE /api/v1/posts/{post_id}`
- `POST /api/v1/posts/{post_id}/like`
- `POST /api/v1/chat`
- `POST /api/chat`

`POST /api/v1/posts` returns the created post id:

```json
{
  "id": 1,
  "message": "게시글이 성공적으로 등록되었습니다."
}
```

## Render

Use the repository root `render.yaml`. For SQLite persistence and FAISS cache, the blueprint mounts a disk at `/var/data`.
Set `OPENAI_API_KEY` in Render environment variables.

```text
DATABASE_URL=sqlite:////var/data/localhub.db
VECTOR_CACHE_DIR=/var/data/vector_cache
```
