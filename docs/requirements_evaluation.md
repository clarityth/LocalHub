## 2. 선택 요구사항 (Optional Requirements)

필수 기능 구현 후 자율적으로 추가한 **선택 기능 목록**입니다. (최소 1개 이상 기준 충족)

### [선택 1] 지도 시각화 (충족 ✅)
- **구현 방식**: `Leaflet.js` 오픈소스 맵 라이브러리를 프론트엔드에 적용하여, 장소 정보 및 맛집 등 좌표(위도 `mapy`, 경도 `mapx`) 데이터를 받아 지도 위에 마커(핀)를 시각적으로 렌더링합니다. 사용자는 채팅 응답 혹은 게시판 연관 장소를 지도 상에서 즉시 확인할 수 있습니다.

### [선택 2] 커뮤니티 게시판 추가 기능 (충족 ✅)
- **구회수 표시**: `posts` 테이블 내 `view_count` 컬럼을 설계하고, 상세 조회 API 호출 시 자동으로 1씩 카운팅되는 구조를 반영했습니다.
- **게시글 검색**: API 엔드포인트 `/posts?q=검색어`를 통해 제목, 본문, 연관 장소명(`place_name`)에 대한 통합 텍스트 검색(ILIKE 매칭)을 지원합니다.
- **좋아요 기능**: 로그인 없는 환경을 고려하여, IP와 브라우저 헤더를 조합해 고유 해시(`fingerprint`)를 생성한 뒤 중복 추천을 차단하는 방식으로 '좋아요'(`like_count`) 기능을 추가 구현했습니다.
